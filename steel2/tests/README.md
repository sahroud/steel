# آزمون‌های ماژول کنترل پی و خاک

این پوشه آزمون‌های بازگشتی ماژول `js/foundation-soil-check.js` را نگهداری می‌کند.

## اجرا

از پوشه `steel2` در محیط دارای Node.js اجرا کنید:

```bash
node --test tests/foundation-soil-check.test.js
```

## پوشش فعلی

- محاسبه فشار ناخالص با احتساب وزن پی و خاک روی پی
- محاسبه فشار خالص با کسر سربار خاک تا تراز زیر پی
- ردکردن حالت‌های ULS در کنترل فشار مجاز خاک
- الزام مرجع گزارش ژئوتکنیک
- الزام نوع کنترل بهره‌برداری `foundation-bearing` و تعریف صریح ترکیب SLS
- تشخیص خروج از مرکزیت خارج از هسته و منع فرض کشش خاک
- تبدیل واحد و علامت واکنش تکیه‌گاهی به کنش وارد بر پی
- رد حل ناموفق، عدم تعادل، محورهای ناسازگار و تکیه‌گاه فاقد مهار انتقالی کامل

## حدود اعتبار

این آزمون‌ها آزمون نرم‌افزاری واحد/API با داده‌های ساختگی هستند؛ تأیید تحلیل یک سوله واقعی، اعتبار ضرایب بار، صحت داده‌های اقلیمی یا تأیید طراحی اجرایی محسوب نمی‌شوند.

طبق بند ۶-۲-۵ مبحث ششم، ترکیب‌های بهره‌برداری باید با نوع کنترل سازه‌ای متناسب باشند. این ماژول عمداً ترکیب SLS عمومی تولید نمی‌کند. تعریف ترکیب و مرجع تحلیل باید توسط مهندس محاسب و بر اساس ضابطه طراحی پروژه ثبت شود.

کنترل فشار خاک در این نسخه فقط برای پی مستطیلی، توزیع خطی تنش و تماس کامل است. نشست، لغزش، واژگونی، ظرفیت نهایی، آب زیرزمینی، اندرکنش پی‌ها، برش یک‌طرفه، پانچ و طراحی آرماتور خارج از دامنه این ماژول‌اند.
