# قالب‌های خالی تبادل مدل مرجع

این فایل‌ها فقط قالب سرستون هستند و هیچ مختصات، عضو یا مشخصه مهندسی نمونه/فرضی ندارند.

- nodes.csv: شناسه یکتا و مختصات X/Y/Z
- members.csv: شناسه یکتا، گره ابتدا/انتها و مرجع مقطع
- supports.csv: درجات آزادی انتقالی/دورانی FIXED یا FREE
- releases.csv: آزادسازی‌های انتهای I/J با RELEASED یا CONNECTED
- section-stations.csv: نسبت ایستگاه 0 تا 1 و ابعاد d,bf,tw,tf

واحد مختصات و واحد ابعاد مقطع را در رابط ورود صریح انتخاب کنید. محور مختصات، مبدأ، راست‌گردی و قرارداد نام‌گذاری انتهای I/J باید از نرم‌افزار مبدأ استخراج و مستند شود. این قالب‌ها بار، ترکیب بار، محور محلی، آفست، فنر، سختی اتصال، لینک صلب و مشخصات کامل مقطع را پوشش نمی‌دهند.

اطلاعات واقعی پروژه را بدون بررسی و تأیید از روی نقشه و مدل مبدأ وارد نکنید.
