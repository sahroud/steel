# رابط ورود مدل مرجع — راهنمای کاربر

در صفحه اصلی SAHROUD STEEL، بخش «ورود مدل از نرم‌افزار مبدأ و پیش‌نمایش سه‌بعدی» اضافه شده است.

1. واحد مختصات گره‌ها را انتخاب کنید.
2. دستگاه مختصات، جهت محورها و مبدأ را دقیقاً ثبت کنید.
3. فایل‌های nodes.csv و members.csv را انتخاب کنید.
4. در صورت وجود، supports.csv، releases.csv و section-stations.csv را نیز انتخاب کنید.
5. «خواندن و کنترل فایل‌ها» را بزنید تا پیش‌نمایش شماتیک، شمارش‌ها و هشدارها ظاهر شوند.
6. برای تطبیق، دو فایل گره و عضو مدل مرجع را انتخاب و «مقایسه با مدل مرجع» را اجرا کنید.
7. «دریافت گزارش JSON» یک بسته بررسی قابل ذخیره می‌سازد.

این رابط فقط داده را می‌خواند و گزارش/پیش‌نمایش می‌سازد. هیچ تغییری در مدل فعال، تحلیل، حلگر یا طراحی ایجاد نمی‌کند. برای استفاده مهندسی باید فایل‌های ورودی با نقشه‌ها و قرارداد نرم‌افزار مبدأ کنترل شوند.
