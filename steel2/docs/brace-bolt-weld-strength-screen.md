# کنترل‌های مقدماتی اتصال پیچی و جوشی مهاربند — SAHROUD STEEL

## مبنا و دامنه

این دو ماژول غربال مقدماتی بر مبنای ANSI/AISC 360-22 هستند. صفحه رسمی AISC نسخه 360-22 را به‌عنوان نسخه منتشرشده استاندارد معرفی می‌کند؛ استفاده از این روابط به معنی انطباق خودکار با مبحث دهم ایران نیست. پیش از طراحی نهایی باید بندها و ضرایب با آیین‌نامه حاکم پروژه تطبیق داده شوند.

## اتصال پیچی — AISC 360-22

- J3.7: مقاومت کششی و برشی پیچ بر اساس (R_n=F_nA_b)، با (phi=0.75) برای LRFD.
- J3.8: در کشش و برش هم‌زمان، تنش کششی اصلاح‌شده طبق J3-3a محاسبه می‌شود:
  (F'_{nt}=1.3F_{nt}-(F_{nt}/(phi F_{nv}))f_{rv}le F_{nt}).
- J3.11a: برای سوراخ گرد استاندارد، مقاومت bearing و tear-out به وضعیت کنترل تغییرشکل سوراخ در بار سرویس وابسته است:
  - با اهمیت تغییرشکل: (R_n=2.4dtF_u)، و (R_n=1.2l_ctF_u).
  - بدون اهمیت تغییرشکل: (R_n=3.0dtF_u)، و (R_n=1.5l_ctF_u).
  - ضریب مقاومت LRFD در این کنترل‌ها 0.75 است.

### قفل‌های اتصال پیچی
- فقط اتصال bearing-type با سوراخ گرد استاندارد و یک صفحه برش پشتیبانی می‌شود؛ اتصال slip-critical به کنترل لغزش جداگانه نیاز دارد.
- خروج از مرکزیت باید صفر باشد و اثر prying باید در تقاضای کشش پیچ لحاظ یا عدم نیاز آن مستند شده باشد.
- Ab، Fnt و Fnv باید از گرید واقعی پیچ، وضعیت رزوه و جدول معتبر وارد شوند؛ مقادیر پیش‌فرض ساخته نمی‌شوند.
- تقاضای کشش، برش و نیروی انتقالی هر پیچ باید برای هر ترکیب بار و هر انتهای عضو صریحاً وارد شود.
- مجموع transferN پیچ‌ها باید با تقاضای کششی همان انتهای عضو در همان ترکیب FEM در محدوده ۱٪ تطبیق داشته باشد. برآیند ‎√(tensionN² + shearPerPlaneN²) هر پیچ نیز باید با transferN همان پیچ در محدوده ۱٪ برابر باشد؛ این نسخه فقط همین نمایش برداری ساده و تک‌صفحه‌ای را می‌پذیرد.
- توزیع مساوی نیرو بین پیچ‌ها فرض نمی‌شود.
- lc در جهت نیرو برای هر پیچ باید مشخص شود.
- پیش‌تنیدگی و لغزش اتصال، سوراخ لوبیایی/بزرگ، چند صفحه برش، محاسبه خودکار prying، گروه پیچ خارج از مرکز و فشار مهاربند در این نسخه محاسبه نمی‌شوند؛ ورودی کشش باید اثر prying را از قبل لحاظ کند.

## اتصال جوشی — AISC 360-22

- J2.2 و J2.4: برای جوش گوشه، گلویی مؤثر برابر (0.707w) و سطح مؤثر برابر گلویی ضرب‌در طول مؤثر است.
- مقاومت فلز جوش برای برش طبق Table J2.5: (F_{nw}=0.60F_{EXX})، با (phi=0.75) در LRFD.
- برای جوش انتهایی بلند، کاهش طول مؤثر طبق J2-1 اعمال می‌شود: برای طول بیش از 100w ضریب (eta=1.2-0.002(l/w)) (حداکثر 1.0)، و برای طول بیش از 300w طول مؤثر به 180w محدود می‌شود.
- فلز پایه نیز کنترل می‌شود: تسلیم برشی (phi=1.00) و (0.60F_yA_{gv})، و گسیختگی برشی (phi=0.75) و (0.60F_uA_{nv}). کوچک‌ترِ دو ظرفیت مبنا قرار می‌گیرد.

### قفل‌های اتصال جوشی
- فقط جوش گوشه تحت برش، گروه هم‌محور و LRFD پشتیبانی می‌شود.
- برای هر ترکیب بار و هر انتهای عضو، نیروی انتقالی و نیروی برشی هر قطعه جوش جداگانه وارد می‌شود.
- مجموع transferN قطعات باید با تقاضای کششی همان انتهای عضو در همان ترکیب FEM در محدوده ۱٪ تطبیق داشته باشد و برای غربال مستقیم برش، shearN هر قطعه نیز باید با transferN آن برابر باشد.
- مساحت‌های ناخالص و خالص برشی فلز پایه باید از نقشه/مسیر شکست مستند وارد شوند.
- ضریب افزایش جهت‌داری عمداً 1.0 گرفته شده است؛ ظرفیت اضافی ناشی از زاویه بار منظور نمی‌شود.
- گروه جوش خارج از مرکز، تحلیل الاستیک/مرکز آنی گروه، جوش شیاری CJP/PJP، plug/slot و بارهای مختلط خارج از دامنه‌اند.

## داده‌های ورودی در پنل اتصال
برای پیچ:
`boltAbMm2`, `boltFntMPa`, `boltFnvMPa`, `connectedFuMPa`, `boltHoleType`, `deformationAtServiceLoad` و `boltCaseDemandsJson`.

ساختار JSON هر ترکیب:
```json
{
  "ULS-1": [
    {
      "transferN": 10000,
      "tensionN": 6000,
      "shearPerPlaneN": 8000,
      "clearDistanceMm": 30
    }
  ]
}
```

برای جوش:
`baseMetalFyMPa`, `baseMetalFuMPa` و `weldCaseDemandsJson`.

ساختار JSON هر ترکیب:
```json
{
  "ULS-1": [
    {
      "transferN": 10000,
      "shearN": 10000,
      "effectiveLengthMm": 100,
      "baseGrossShearAreaMm2": 500,
      "baseNetShearAreaMm2": 450
    }
  ]
}
```

آرایه باید به تعداد پیچ‌ها یا قطعات جوش رکورد داشته باشد. JSON باید برای همه ترکیبات FEM وارد شود.
