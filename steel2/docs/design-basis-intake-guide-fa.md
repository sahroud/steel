# دفتر ثبت مبنای طراحی — راهنما

این فرم برای ثبت داده‌های ورودی پروژه است، نه تولید یا تأیید طراحی.

- هر مقدار باید با سند مبدأ، واحد، تاریخ/ویرایش و مسئول بررسی قابل ردیابی باشد.
- فیلد خالی به معنی «نامشخص/دریافت‌نشده» است؛ هیچ مقدار پیش‌فرض یا حدسی به آن تحمیل نمی‌شود.
- ظرفیت باربری خاک باید از گزارش ژئوتکنیک معتبر همان محل اخذ شود.
- اطلاعات جرثقیل باید با دیتاشیت سازنده و واکنش‌های چرخ هر حالت بارگذاری تطبیق داده شود.
- مبنای آیین‌نامه و ویرایش هر مبحث باید برای پروژه صریح باشد.
- خروجی JSON فقط بسته گردآوری شواهد است؛ به مدل فعال، تحلیل یا حلگر وارد نمی‌شود.
