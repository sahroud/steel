# ممیزی مسیر انتقال بار جرثقیل — SAHROUD STEEL

## هدف
تفکیک مسیر بار چرخ جرثقیل سقفی از بارهای کف سوله و جلوگیری از اعمال اشتباه واکنش چرخ جرثقیل سقفی به دال کف.

## انواع پشتیبانی
- `overhead`: جرثقیل سقفی؛ مسیر: چرخ ← ریل ← تیر حمال ← براکت/کنسول ← ستون ← صفحه‌ستون و انکر ← فونداسیون ← خاک.
- `gantry`: جرثقیل دروازه‌ای زمینی؛ تکیه‌گاه باید صریحاً کف طراحی‌شده، تیر/نوار بتنی یا فونداسیون مستقل باشد.
- `floor_rail`: تجهیز/جرثقیل روی ریل زمینی؛ مسیر به کف، تیر/نوار بتنی یا فونداسیون مستقل متصل می‌شود.

## API
`window.SteelCraneLoadPath`
- `classify({craneType,supportSystem})`
- `auditCases([{id,craneType,supportSystem}])`
- `routeWheelActions(crane, actions)`
- `selfTest()`

`routeWheelActions` فقط مؤلفه‌های نیرو را به هدف مجاز برچسب می‌زند؛ هنوز بار را به FEM تزریق نمی‌کند.

## محدودیت‌ها
- بار چرخ، ضربه، نیروهای افقی، توزیع بین چرخ‌ها و ترکیبات بار در این ماژول محاسبه نمی‌شوند.
- دال کف فقط در صورت انتخاب صریح جرثقیل زمینی و تکیه‌گاه slab هدف مسیر می‌شود؛ این انتخاب به معنی کفایت دال نیست.
- طراحی دال، زیرسازی، بستر، درزها، پانچ/خمش موضعی و فونداسیون ریل در ماژول‌های جداگانه لازم است.
- `analysisEnabled=false` و `designApproved=false` باقی می‌مانند.

## آزمون
۱۲ آزمون نرم‌افزاری طبقه‌بندی و اعتبارسنجی مسیر؛ نه آزمون مرورگر، FEM یا تأیید آیین‌نامه‌ای.
