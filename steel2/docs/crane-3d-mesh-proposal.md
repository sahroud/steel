# پیشنهاد توپولوژی سه‌بعدی تیر حمال جرثقیل

## هدف
تبدیل هندسه کمکی جرثقیل به یک پیشنهاد توپولوژی قابل ممیزی، بدون دستکاری شبکه حل‌گر و بدون اعمال بار.

## تطبیق گره ستون
برای هر قاب طولی و هر سمت، گره ستون در مختصات دقیق زیر جست‌وجو می‌شود:
- سمت چپ: x=0
- سمت راست: x=دهانه
- y=تراز ریل
- z=ایستگاه قاب

تلورانس تطبیق 1e-7 متر است. باید دقیقاً یک گره منطبق وجود داشته باشد و دست‌کم به یک عضو واقعی با sectionKey برابر column متصل باشد. گره مفقود یا تکراری/مبهم موجب رد تطبیق می‌شود. هیچ nearest-node matching انجام نمی‌شود.

## اجزای پیشنهادی
- گره‌های مستقل روی محور تیر حمال در فاصله offset از ستون.
- قطعات تیر حمال بین قاب‌های مجاور؛ وضعیت آن‌ها صریحاً separate-span باقی می‌ماند.
- هندسه براکت از گره ستون تا گره تیر حمال، با طول و نوع اتصال ثبت‌شده.

## محدودیت قطعی
این داده‌ها فقط proposal هستند و به model.nodes یا model.members اضافه نمی‌شوند. مقطع/خواص تیر حمال و براکت، سختی و release اتصال، خروج از مرکزیت، پیوستگی واقعی و جزئیات اجرایی هنوز برای تحلیل تعیین نشده‌اند. در نتیجه ready=false و analysisEnabled=false باقی می‌مانند و هیچ بار جرثقیل به حل‌گر تزریق نمی‌شود.

## API
`window.SteelCrane3DMeshProposal.audit(model)`
`window.SteelCrane3DMeshProposal.selfTest()`

این ممیزی نرم‌افزاری، تأیید طراحی یا انطباق آیین‌نامه‌ای نیست.
