# یکپارچه‌سازی واقعی تیر حمال و براکت در شبکه 3D

## پیاده‌سازی
ماژول `crane-3d-integration.js` از توپولوژی پیشنهادی گره‌های دقیق ستون استفاده می‌کند و یک کپی مستقل از مدل تولید می‌کند:
- گره‌های محور تیر حمال در مختصات اندازه‌گیری‌شده
- اعضای تیر حمال بین قاب‌های متوالی
- اعضای براکت بین گره ستون و گره تیر حمال در هر قاب
- مقطع اختصاصی هر گروه با خواص SI و مرجع نقشه/کاتالوگ
- آزادسازی انتهایی محلی 4 و 5 به‌صورت صریح برای هر دو انتهای اعضا

## قرارداد ورودی JSON
```json
{
  "girderSection":{"E_Pa":200000000000,"G_Pa":77000000000,"A_m2":0.01,"Iy_m4":0.0001,"Iz_m4":0.0002,"J_m4":0.00001,"source":"نقشه مقطع تیر حمال"},
  "bracketSection":{"E_Pa":200000000000,"G_Pa":77000000000,"A_m2":0.01,"Iy_m4":0.0001,"Iz_m4":0.0002,"J_m4":0.00001,"source":"نقشه براکت"},
  "girderEndReleases":{"i":[],"j":[]},
  "bracketEndReleases":{"i":[],"j":[]},
  "connectionType":"moment",
  "connectionSource":"شماره نقشه اتصال",
  "geometrySource":"شماره نقشه جانمایی"
}
```

مقادیر عددی بالا فقط قالب مثال‌اند و نباید به‌عنوان مقطع واقعی استفاده شوند. آزادسازی‌ها فقط درجات آزادی خمشی محلی 4 و 5 را می‌پذیرند؛ انتخاب آن باید با جزئیات اتصال تطبیق داده شود. اتصال فنری هنوز پشتیبانی نمی‌شود.

## رابط کاربری و ذخیره پروژه
در پنل «مدل هندسی کامل سوله»، بخش «ورودی مقطع و اتصال برای شبکه واقعی سه‌بعدی» یک کادر JSON وجود دارد. ورودی با ذخیره پروژه ثبت و هنگام بازیابی بارگذاری می‌شود. تا وقتی خواص هر دو مقطع، آزادسازی انتهایی و دو مرجع نقشه کامل نباشند، اعضای جرثقیل به کپی مدل FEM افزوده نمی‌شوند.

## حل‌گر
اعضای جدید دارای `analysisSection` با خواص مستقیم SI هستند. resolver مقطع سه‌بعدی این خواص را فقط برای اعضای جرثقیل می‌پذیرد، مشروط به کامل بودن همه خواص و منبع.

## مرز ایمنی
این گام اعضای واقعی را به یک کپی مدل FEM اضافه می‌کند؛ هنوز بار جرثقیل اعمال نمی‌کند. انتقال بار قائم/افقی، رفتار موضعی ورق و جوش و پیچ، سختی واقعی اتصال، خستگی، اثر دینامیکی و کنترل آیین‌نامه‌ای همچنان جداگانه لازم‌اند. `analysisEnabled=false` حفظ می‌شود.
