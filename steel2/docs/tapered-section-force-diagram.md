# نمودار نیرو در اعضای متغیرمقطع — SAHROUD STEEL

## دامنه
ماژول `js/tapered-section-force-diagram.js` نمودارهای نیروی داخلی را برای هر قطعه تحلیل عضو متغیرمقطع، جداگانه و برای هر ترکیب بار بازسازی می‌کند. از بازسازی‌کننده عضو منشوری موجود استفاده می‌کند، اما فقط در سطح هر قطعه‌ای که در مدل FEM با مقطع ثابت تعریف شده است.

## ورودی‌های الزامی
- مدل تحلیل قطعه‌بندی‌شده با `nodes` و `members`؛
- شناسه عضو فیزیکی والد، شماره قطعه و تعداد قطعات؛
- گره ابتدا و انتهای هر قطعه برای محاسبه طول واقعی؛
- نتیجه مستقل هر ترکیب بار با نام یکتا، `equilibrium.ok === true` و بردار ۱۲ مؤلفه‌ای نیروهای انتهایی هر قطعه؛
- بردار بار گسترده یکنواخت محلی سه‌مؤلفه‌ای؛
- تأیید صریح کامل‌بودن دفتر بارگذاری روی طول قطعه از طریق `analysisLoad.loadDataComplete === true`، `loadDataComplete` یا `options.loadCompletenessByMember[id] === true`.

## رفتار محافظه‌کارانه
- قطعات بر اساس شماره مرتب و پیوستگی گره انتهایی/ابتدایی بررسی می‌شوند.
- طول از مختصات واقعی دو گره محاسبه و با طول ثبت‌شده، در صورت وجود، تطبیق داده می‌شود.
- هر ترکیب بار مستقل نگه داشته می‌شود؛ نمودارها یا نیروهای دو ترکیب با هم مخلوط نمی‌شوند.
- نمودار هر قطعه در دستگاه محلی خودش می‌ماند و مختصات طولی تجمعی عضو فیزیکی نیز گزارش می‌شود.
- بار متمرکز و بار گسترده غیریکنواخت/قطعه‌ای در این نسخه پشتیبانی نمی‌شود و باعث اعلام داده ناکافی می‌شود.
- آزادسازی انتهایی و خروج از مرکزیت فقط مطابق محدودیت‌های بازسازی‌کننده پایه پذیرفته می‌شوند.
- اگر دفتر بارگذاری صریحاً کامل اعلام نشده باشد، وجود یک بردار `uniformLocal` به‌تنهایی برای ساخت نمودار کافی نیست.

## فراخوانی
```js
const report = SteelTaperedSectionForceDiagram.build(
  segmentedModel,
  perCombinationResults,
  {
    loadCompletenessByMember: {
      "R1_TAPER_01": true,
      "R1_TAPER_02": true
    }
  }
);
```

در کاربرد واقعی، مقدارهای `true` باید از ممیزی واقعی دفتر بارگذاری و بارهای گره‌ای/عضوی ناشی شوند؛ صرفاً برای عبور از کنترل وارد نشوند.

همین قابلیت پس از بارگذاری اسکریپت، از طریق `SteelTaperedCaseForceBridge.buildSectionForceDiagrams(model, rawPerCombinationResults, options)` نیز در دسترس است. ورودی آن باید نتایج خام FEM هر ترکیب باشد، نه خروجی خلاصه‌شده‌ای که بردارهای نیرو یا دفتر بار را حذف کرده باشد.

## مرز اعتبار
این گزارش فقط بازسازی تقاضای نیرو است. ظرفیت، پایداری، کمانش موضعی/کلی، خیز، همگرایی قطعه‌بندی، کنترل آیین‌نامه‌ای یا تأیید طراحی را محاسبه نمی‌کند. نیروهای قطعات مجاور نیز در یک دستگاه محلی مشترک میانگین‌گیری یا به هم پیوند داده نمی‌شوند.
