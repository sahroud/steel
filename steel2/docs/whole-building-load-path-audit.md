# ممیزی مسیر بار کل سوله

این ماژول، تخصیص موجود بارهای سطحی ثبت‌شده در `SteelLoads` به اعضای مدل سه‌بعدی را ممیزی می‌کند. دسته‌های بررسی‌شده: بار مرده، زنده و برف بام روی رفتر/پرلین؛ باد بام روی پرلین؛ باد دیوار طولی روی لاپه دیوار؛ و باد دیوار انتهایی روی لاپه انتهایی.

## اجرا
پس از بارگذاری صفحه و ساخت مدل هندسی، از پنل «ممیزی مسیر بار کل سوله» گزینه اجرای ممیزی را انتخاب کنید. API برنامه‌نویسی:
`SteelWholeBuildingLoadPathAudit.audit(model, loads)`,
`SteelWholeBuildingLoadPathAudit.run()`,
`SteelWholeBuildingLoadPathAudit.selfTest()`.

## تفسیر
وضعیت assigned صرفاً یعنی مقدار عددی مورد انتظار در رکورد عضو وجود دارد و هندسه بارگیر اولیه ثبت شده است. این وضعیت، درستی مقدار بار، ضریب آیین‌نامه‌ای، ترکیب بار، توزیع واقعی فشار، اتصال مهاربندها، یا کفایت طراحی را اثبات نمی‌کند. ورودی‌های باد باید فشار خالص مستند بر حسب kN/m² باشند؛ این ماژول سرعت مبنای باد را به فشار طراحی تبدیل نمی‌کند.

## ایمنی
این ماژول مدل یا بارهای حل‌گر را تغییر نمی‌دهد و هرگز `analysisEnabled` یا `designApproved` را فعال نمی‌کند. آزمون‌ها فقط منطق ممیزی نرم‌افزاری را می‌سنجند.
