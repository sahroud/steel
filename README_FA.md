# SAHROUD STEEL — اسکلت چندفایلی

## این نسخه چه دارد؟
- رابط فارسی و ورودی پروژه
- اعتبارسنجی اولیه هندسه
- پیش‌نمایش شماتیک
- ذخیره اطلاعات پروژه در JSON
- تفکیک فایل‌های CSS و JavaScript

## چه چیزی هنوز ندارد؟
این اسکلت، موتور تحلیل و طراحی سازه نیست. تحلیل ماتریسی، بارهای آیین‌نامه‌ای معتبر، طراحی اعضا/اتصالات/فونداسیون، DXF و گزارش PDF اجرایی هنوز ساخته و اعتبارسنجی نشده‌اند. از آن برای ساخت سوله استفاده نکنید.

## انتشار در GitHub Pages
1. در مخزن خود، فایل‌ها و پوشه‌ها را با همین ساختار آپلود کنید.
2. `index.html` باید در ریشه مخزن باشد.
3. Settings → Pages → Deploy from branch → شاخه `main` و پوشه `/root` را انتخاب کنید.
4. آدرس Pages را باز کنید و ابتدا ذخیره JSON و پیش‌نمایش را آزمایش کنید.

## مرحله بعد
مرحله بعدی توسعه، تعریف مدل قاب دوبعدی و حل ماتریسی با واحدهای مشخص، سپس آزمون با مثال دستی/مرجع است. تا زمانی که تحلیل و کنترل‌ها تأیید نشده‌اند، هیچ خروجی نباید عنوان «طراحی قطعی» یا «نقشه اجرایی» داشته باشد.
